# 파트별 직책과 담당 배정

2026-10-21 사용자 요청 기준. 로컬 구현이며 DB17·18 및 실제 계정 배정은 운영 미반영입니다.

| 파트 | 선택 직책 |
|---|---|
| 교육부서 | 교역자 / 총괄 |
| 베리타스 기독초·기독국제중 | 총괄 / 담임 / 파트 |
| 예배팀 | 담당교역자 / 예배인도자 |
| 음향팀·조명팀·자막팀 | 담당교역자 / 오퍼레이터 |
| 영상팀 | 담당교역자 / 예배총괄 / 팀장 / 부팀장 |
| 웰컴·성찬·성찬준비·새가족·새가족케어·사진팀 | 담당교역자 |
| 부산 캠퍼스·스데반 인턴십 | 담당교역자 |

## 권한 연결

- 교역자·담당교역자: 해당 파트 교역자 권한. 교역자로 지정된 계정에만 이 직책을 배정할 수 있습니다.
- 총괄·예배총괄·팀장·부팀장: 해당 파트 일반 보고 열람, 본인 보고 작성. 타인 보고 수정·확인과 비공개 열람은 주어지지 않습니다.
- 담임·파트·예배인도자·오퍼레이터: 작성자 권한.

한 사람이 조명에서는 교역자, 영상에서는 총괄, 음향에서는 오퍼레이터일 수 있습니다. 비공개 열람·타인 보고 수정·확인은 실제 교역자로 맡은 파트에 한정합니다. 일반 보고의 동급 열람은 맡고 있는 각 직급을 기준으로 하며, 새 보고에는 작성 파트의 당시 직급을 보존합니다. 과거 보고의 직급이나 내용을 소급 변경하지 않습니다.

기존 직책 미지정 소속은 보존합니다. 기존 값을 유지해 저장할 수 있으나, 새 직책을 선택한 뒤 임의의 미분류 값으로 바꿔 권한을 우회할 수 없습니다. 자기 소속 변경 제한도 유지합니다.

운영 승인 후 확인된 본인 계정의 관리자 역할은 유지하고 교역자 플래그를 지정한 뒤 위 6개 소속을 추가·갱신합니다. 다른 소속과 다른 사람의 역할은 변경하지 않습니다. 이 배정은 마이그레이션에서 자동 실행하지 않습니다.

11월 4일에는 관리자 셋업용 임시 권한만 만료됩니다. 정식 담당·동급·작성자 권한으로 허용된 열람은 유지됩니다.

## 반영 범위와 순서

운영 DB16 → 미반영 DB17(관리자 자기 보고 작성) → DB18 `20261101000000_group_positions.sql`(사진팀·직책·파트별 직급) → 승인된 본인 계정 6개 배정 → 앱 배포 순서입니다. 실제 계정 ID·개인정보는 문서와 커밋에 기록하지 않습니다.

검증: 직책 선택지의 앱/DB 일치, 사진팀 및 예배 연결, 한 사람의 1·2·3 직급 공존, 교역자 담당 범위와 비공개 차단, 직책 위조/비교역자 교역자 배정/자기 소속 변경 차단, 기존 보고·소속 보존을 자동 테스트합니다.

# 관리자 제출현황과 셋업용 임시 열람

2026-10-21 사용자 승인 후 DB16과 본인 관리자 계정 한 개의 임시 일반 열람을 운영에 적용했습니다.

- 모든 활성 기능 관리자는 전체 파트의 작성자·예배·날짜·제출 상태·제출 시각을 계속 조회합니다. 본문, 기도제목, 비공개 글, 명단, 보호자 연락처, 모임 없음 사유는 현황 응답에 포함하지 않습니다.
- 일반 보고·일반 이슈의 셋업용 열람은 승인된 관리자 계정 한 개에 별도로 등록합니다. 시작·종료 시각을 DB에서 매 요청 검사하고, 최대 14일을 초과하는 등록을 거부합니다.
- 이번 제안 만료: **2026-11-04 00:00 Asia/Seoul**. 운영 승인 시점부터 이 시각까지 적용합니다. 만료 후에도 관리자 제출현황은 계속 보입니다.
- 임시 권한은 읽기만 허용합니다. 비공개 열람, 아이들 명단·보호자 연락처, 보고 수정·확인·공유, 자기 소속 변경, 임시 권한 생성·연장을 허용하지 않습니다. 이미 보유한 정식 담당 권한은 별도로 유지됩니다.
- 관리자 역할 해제 또는 계정 비활성 시 임시 열람도 즉시 거부합니다. 정식 교역자 역할이나 담당 파트를 임의로 배정하지 않습니다.

## 적용 단위

1. 별도 승인 후 `20261030000000_admin_submission_setup.sql`(16번)을 적용합니다. 기존 보고 행은 변경하지 않으며 report 스키마만 사용합니다.
2. 승인된 본인 관리자 계정을 확인하고 `setup_access_grants`에 시작 시각과 위 만료 시각을 등록합니다. 마이그레이션은 임시 열람 계정을 자동 등록하지 않습니다. 현재 관리자 수만으로 대상을 임의 선택하지 않습니다.
3. 관리자 전체 현황과 임시 일반 내용 열람을 확인하고 앱을 배포합니다. 취소 시 해당 grant를 만료시키면 정식 권한 외 임시 내용 열람이 닫힙니다.

제출 완료 팝업은 성공 응답의 `saved=submit`과 DB의 제출 상태·수정 권한이 함께 확인될 때만 표시합니다. 임시저장·실패에는 표시하지 않으며, 확인 또는 Escape로 닫으면 성공 URL 표시를 제거합니다.

실제 계정의 임시 권한·운영 DB16·앱 배포를 완료했습니다. 운영에서 전체 현황과 기존 수요예배 보고의 읽기 전용 열람 및 타인 비공개 차단을 확인했습니다. 정식 교역자/담당 파트 배정과 실제 보고 제출·알림 테스트는 하지 않았습니다. 자세한 운영 검증은 HANDOFF.md 35절을 참고합니다.

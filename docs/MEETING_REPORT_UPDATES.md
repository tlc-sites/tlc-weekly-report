# 보고·명단·모임별 마감 변경

운영 적용 전 준비 상태입니다. 기존 DB19·20 배포 승인과 별개로 이번 DB21 및 예약 실행 활성화 승인이 필요합니다.

- 보고 본문 아래 코멘트와 원 코멘트별 답글을 제공합니다. 원 코멘트는 교역자 이상, 답글은 해당 원문을 열람할 수 있는 활성 사용자만 작성합니다.
- 제출 성공 팝업의 확인/Escape로 닫으면 해당 팀의 주간 보고 메인으로 돌아갑니다.
- 안내팀·송번역팀을 추가합니다. 기존 팀·보고·소속은 삭제하거나 이름을 바꾸지 않습니다.
- 부산은 예배 / 장년부 / 청년부 / 교회학교 / 오벧에돔 / 새가족 현황 / 웰컴팀 / 새가족 훈련을 펼쳐 작성합니다. 한 항목 이상 작성하여 제출하며 기존 방문·경비·사역 자료는 별도 접힘 영역에 유지합니다.
- 주중 기도회에 기도인도자·참석명단·기도제목을 기록합니다. 교역자 이상 공동 열람 규칙을 유지합니다.
- 교회학교 출생연도는 표시 이름에만 추가합니다. 중등부·고등부는 사용자 확인에 따라 별도로 유지합니다.
- 팀 구성 명단은 로그인 프로필/소속/보고 작성 권한과 별개입니다. 담당 교역자와 최상단이 이름·담당 역할을 추가하거나 활동 제외/복귀 처리하며 원래 기록은 보존합니다. 해당 파트 소속은 명단을 읽을 수 있고, 무관 교역자·기능 관리자 단독에게 공개하지 않습니다.

## 모임 마감

한국 시간 기준으로 종료 3시간 뒤부터 미제출 담당자와 두 분에게 2시간마다 안내합니다. 작성 중인 초안은 제출로 보지 않습니다. 같은 시간대 중복 호출은 DB에서 차단하고, 담당자별 제출을 확인하므로 한 예배에 여러 담당자의 보고가 가능합니다. 알림 거부 설정과 비활성 계정은 존중합니다.

| 예배 | 종료 | 최초 미제출 안내 |
|---|---|---|
| 1부 | 일 10:20 | 일 13:20 |
| 2부 | 일 12:40 | 일 15:40 |
| 3부 | 일 15:00 | 일 18:00 |
| 라이프라인 | 일 22:00 | 월 01:00 |
| 금요예배 | 금 23:00 | 토 02:00 |
| 수요예배 | 수 12:00 | 수 15:00 |

금요예배는 기존 월별 주차 규칙을 따릅니다. 부서 모임은 담당 교역자가 파트의 ‘모임 시간 설정’에서 요일·종료 시각·모임 이름을 등록합니다. 보고의 모임 이름 또는 등록된 모임 유형 이름과 일치해야 합니다. 시간이 없는 부서에 임의 시각을 넣지 않습니다. 새 시간 설정/변경·재사용 이후 종료하는 모임부터 적용합니다. ‘이번 주 모임 없음’은 해당 주 알림에서 제외합니다. 제출하지 않은 기간에는 밤에도 반복됩니다.

현재 자동 계산 대상은 파트 소속 중 작성자, 교역자 직책, 직책 미분류 교역자입니다. 계정 없이 명단에만 등록한 팀원은 제출 의무나 알림 대상이 되지 않습니다. 상세 예배별 담당 로테이션은 현재 소속 배정 상태에 따라 운영 담당자가 점검해야 합니다.

## 예약 실행 설정

Vercel Hobby의 일 단위 크론 제한을 피해 GitHub Actions의 별도 예약 실행을 준비했습니다. 기존 `vercel.json`의 세 가지 알림은 보존합니다. 다음 설정 전까지 새 예약 실행은 비활성입니다.

1. 운영 DB19→20→21을 기존 데이터 보존 검사와 함께 적용합니다.
2. 앱을 배포한 뒤 저장소 Actions Secret `REPORT_CRON_SECRET`에 운영 `CRON_SECRET`과 같은 값을 안전하게 등록합니다. 값은 문서/명령 인자/로그/커밋에 기록하지 않습니다.
3. 저장소 변수 `REPORT_MEETING_REMINDERS_ENABLED`를 `true`로 설정합니다.
4. `.github/workflows/meeting-reminders.yml` 수동 실행으로 인증·결과를 확인합니다. 이 단계는 실제 미제출 알림을 발송할 수 있으므로 운영 반영 승인 범위에서 수행합니다.

5분 간격으로 `/api/cron/meeting-deadlines`를 호출합니다. 실제 전송은 예약 실행 지연만큼 늦을 수 있으며 정각 전송을 보장하지 않습니다. 2시간 간격은 종료+3시간을 기준으로 계산합니다. 발송 실패는 결과에 집계되고 다음 2시간 구간에 다시 시도됩니다. 기능 중단은 저장소 변수를 `false`로 바꿉니다. 임의 요금제 변경이나 외부 계정 생성은 하지 않았습니다.

검증: DB88개, lint, TypeScript, webpack build(35경로) 통과. 운영 DB 적용·자동 알림 활성화·실기기 전송·브라우저 화면 검증은 아직 수행하지 않았습니다.
